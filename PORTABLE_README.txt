TF2 Schema Workshop — Portable Windows Build

START
1. Extract the entire ZIP to a folder.
2. Double-click TF2SchemaWorkshop.exe.
3. In the app, select Sync TF2. Browse to your Team Fortress 2 folder if it is
   installed in a non-default Steam library.

This portable build includes its Python runtime and does not require Python to
be installed separately. It does not include Team Fortress 2 game files. Sync
uses your local TF2 installation.

LOCAL DATA AND SAFETY
The app runs locally and listens only on this computer. Drafts and settings are
stored in your Windows local app-data folder. It does not modify the installed
TF2 schema; use Save schema copy to export a separate file.

Keep all files in the extracted folder together. Close the console window to
stop the app. Windows may show a SmartScreen warning because this build is not
code-signed.
